# 글 뼈대: "LLM으로 개발한다"는 게 뭔지 몰랐다

## 핵심 주제
스펙트럼이 있다는 걸 몰라서 안 보였다.
지도가 생기면 내가 어디 있는지, 다음이 뭔지 보인다.

## 대상 독자
LLM 앱은 매일 쓰는데, "LLM으로 개발"이라는 말은 자기 얘기 같지 않은 사람.
(개발자 대상 스펙트럼 개념 정리 글과의 차별점: 지도가 있다는 것 자체를 모르는 사람의 시점)

---

## 훅 (첫 문단 방향)
유튜브에서 "LLM으로 영상 제작 프로그램 개발해서 수익화"를 봤다. '개발'이 뭔지 감이 안 왔다.
프론트엔드 개발자로서 리액트 프로젝트는 구조가 보이는데, LLM 개발은 뭘 만드는 건지 몰랐다.
그래서 찾아봤다.

---

## TL;DR 다이어그램
**LLM 활용 스펙트럼 — 얼마나 미리 구축하느냐**

```
1단계              2단계                    3단계
데스크탑 앱 사용 → 시스템 프롬프트 설정 → LLM 기반 시스템 구축
(Claude, ChatGPT)  (Project, Gems, GPTs)   (워크플로우 → 에이전트)
                                            ↑ "LLM으로 개발"이 이 범위
```

---

## 섹션 구성

### 1. 뭘 만든 건지 몰랐다
- **핵심 내용**: "개발"의 의미가 모호했다. 프론트엔드 개발처럼 결과물이 눈에 보이지 않음.
- **내용**: 영상 제작 프로그램 = 별도 UI 없이 클로드 코드를 클라이언트로, LLM 워크플로우를 구축한 것으로 이해. 일반인 대상이라 "프로그램 개발"이라 표현한 것.
- **독자가 얻는 것**: "나도 이거 봤는데 뭔지 몰랐음" 공감

### 2. 찾아봤는데 계속 맴돌았다
- **핵심**: 세 방향으로 찾아봤지만 답이 매번 "필요에 따라 달라짐"이었다.
  - "개발"의 의미 → 워크플로우, MCP, RAG, DB 등 필요한 모든 것
  - 프로젝트 구조와 클라이언트 형태 → 클로드 코드, 스크립트, UI 앱 등 엔트리포인트는 다양
  - 세부 프로세스 → 마찬가지로 필요에 따라
- **독자 공감**: 정보를 찾았는데 오히려 더 막막해지는 느낌
ㅇ
### 3. 맴돈 이유: 지도 없이 찾고 있었다
- **핵심**: 돌아보니, 내가 1단계(단순 채팅) 사용자였기 때문에 3단계가 왜 필요한지 자체가 안 보였다. 스펙트럼이 있다는 틀 없이 개별 개념만 찾으니 연결이 안 됐던 것.
- **예시 시나리오**: 같은 목표(영상 스크립트 자동화)를 1단계와 3단계로 나란히 보여주기
  - 1단계: 매번 대화창 열고 "이번 주제는 OO야, 스크립트 써줘"
  - 3단계: 주제만 넣으면 리서치 → 구조화 → 스크립트 → 검수까지 자동 실행
  - → 같은 목표인데 사람 개입이 이렇게 달라진다
- **독자 공감**: "나도 그게 왜 필요한지 몰라서 안 와닿았다"

### 4. 스펙트럼이 보이자 풀렸다
- **핵심**: LLM 활용에는 단계가 있고, 얼마나 사람 개입을 줄일 것인지에 따라 미리 구축하는 범위가 달라진다.
- **스펙트럼 설명**: 1단계(데스크탑 앱) → 2단계(시스템 프롬프트 설정) → 3단계(LLM 기반 시스템 구축)
- **자가진단**: 스펙트럼을 설명한 직후, 독자가 자기 위치를 대입하도록
  - 매번 대화창 열고 요청 → 1단계
  - 반복 지시사항을 시스템 프롬프트로 고정 → 2단계
  - 특정 형식의 결과물을 일정 품질로 뽑아야 함 → 3단계
- **기술 개념 링크**: 워크플로우 패턴 / 에이전트 상세는 별도 글 참고 → [링크 예정]
- **독자가 얻는 것**: "LLM 개발"이 자기 얘기가 될 수 있다는 감각

### 5. 마무리: 다음이 보인다
- **핵심**: 나는 1, 2단계를 이미 쓰고 있었다. 스펙트럼이 보이고 나서 "그러면 3단계를 써볼 만한 지점이 내 일상에 어디 있지?"라는 질문이 생겼다. 그걸 찾아보는 게 다음이다.
- **톤**: 다짐이 아니라 자연스러운 탐구 욕구. 글 전체 주제(지도가 생기면 다음이 보인다)와 맞닿는 마무리.
